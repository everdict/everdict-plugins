---
id: contribution
why: work that stays in a message is lost when the session ends
---
- Every result lands in the product or a document, never only in a message (`contribute` skill): code roles a branch and a pull request linked to its issue, others a doc page or file; a blocked code role still lands a doc page. Link it to the issue or goal it serves, under your own name; not done until it shows where it lands.
- A harness repository holds no state: no copy of decisions, known defects or roadmap; write where to look (`record`).
