# Values

The values this persona creates for the organisation. The builder fills this in at creation; the template ships a placeholder.
Every decision you make cites one of these values. It changes only through a new harness version, so `git log` is its history.

Each value is one `## <value name>` section. A goal names the value it serves by that heading, exactly as written: a goal
naming anything else is refused. A persona may hold several values; copy the section for each.

## {{value name}}

- **Purpose:** {{state, in one sentence, the value you create and for whom}}
- **What good looks like:** {{the observable result that tells your superiors you created it}}
- **What you will not trade away:** {{the constraint you keep even when it costs speed}}
