# Claim template

Copy the frame, fill every line, and delete nothing — a line you cannot fill is itself the finding.

    TITLE       the claim in one sentence, specific enough that two entries are never confused
    KIND        finding | decision | convention | context
    CLAIM       what is true, stated so it can be contradicted
    DETECTION   how it was found, precisely enough to be re-run
    EVIDENCE    the runs / reports / rounds / captures behind it
    SUBJECTS    the entities this is about, version-pinned
    SCOPE       where it holds — and where it does NOT
    CHOSEN AGAINST   (decision only) the alternative and why it lost
    MECHANISED  the regression case this produced, or "none — <reason>"
    SUPERSEDES  (if it revises one) the earlier claim it replaces
    VISIBILITY  shared, unless there is a reason it should not be

## Kinds

- **finding** — something observed about the world. Needs evidence and a detection method.
- **decision** — a choice made, with the alternative it beat. Without that, it is a preference.
- **convention** — how work is done here from now on. Say what happens when it is not followed.
- **context** — background that orients a reader. No claim to defend; do not dress one up as a finding.

## Before filing

- [ ] Would a reader who disagrees know what evidence would change their mind?
- [ ] Are the independent observations counted, rather than the entries citing them?
- [ ] Does it record the attempt that failed, not only the one that worked?
- [ ] Is it reachable from the request that caused it — verified, not assumed?
- [ ] If it revises an earlier claim, does it supersede rather than overwrite?
